# PymeGest

Proyecto académico correspondiente a la **Fase 1: Maquetación del sitio con HTML y CSS** de la asignatura Desarrollo de Aplicaciones Web (ISW-306).

## Descripción

PymeGest es una propuesta de aplicación web orientada a facilitar la gestión de pequeñas y medianas empresas.

## Fase 1

La maquetación incluye:

- Página de inicio.
- Página informativa.
- Formulario maquetado.
- Navegación entre las páginas.
- Estructura HTML5 semántica.
- Hoja de estilos CSS.
- Identidad visual coherente.
- Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías

- HTML5
- CSS3
- Git
- GitHub
